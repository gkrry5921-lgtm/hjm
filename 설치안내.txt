H군의 데일리 체크리스트 - 아이폰 푸시 (Spark 무료 + GitHub Actions)

[아직 실제 푸시 발송이 활성화된 것은 아닙니다. 아래 설정이 필요합니다.]

1. Firebase 콘솔 > 프로젝트 설정 > 클라우드 메시징 > 웹 푸시 인증서:
   기존 '키 쌍'의 공개 키 전체를 복사합니다. (비밀 키가 아닙니다.)
   index.html에서 PASTE_YOUR_FIREBASE_WEB_PUSH_PUBLIC_KEY_HERE 문자열을 공개 키로 교체합니다.

2. GitHub hjm 저장소에 다음 파일을 업로드합니다:
   index.html
   firebase-messaging-sw.js
   scripts/send_push.py
   .github/workflows/daily-push.yml
   GitHub 웹 업로드에서는 경로를 유지해야 합니다.

3. Firebase 콘솔 > 프로젝트 설정 > 서비스 계정 > 새 비공개 키 생성:
   내려받은 JSON 파일은 절대 GitHub 저장소나 채팅에 업로드하지 마세요.
   GitHub 저장소 > Settings > Secrets and variables > Actions > New repository secret
   이름: FIREBASE_SERVICE_ACCOUNT_JSON
   값: JSON 파일의 전체 내용
   권장: 가능한 최소 권한의 서비스 계정 사용 및 키 관리/교체.
   중요: 이 서비스 계정은 GitHub Actions에서 Firestore를 읽고 FCM을 발송합니다.

4. Firebase Firestore 보안 규칙:
   users/{uid}/hjm_push_tokens/{tokenId}에 로그인한 본인만 생성/읽기/수정/삭제할 수 있도록
   규칙을 추가해야 합니다. 기존 다른 규칙은 절대 삭제하지 마세요.
   예시(기존 match /users/{userId}/{collection}/{docId} 와 충돌 여부 확인):
   match /users/{userId}/hjm_push_tokens/{tokenId} {
     allow read, write: if request.auth != null && request.auth.uid == userId;
   }
   다른 사람의 푸시 토큰이 노출되지 않도록 반드시 확인하세요.

5. 아이폰 iOS 16.4 이상:
   Safari에서 사이트를 열고 공유 > 홈 화면에 추가.
   홈 화면의 H군 앱 실행 > Google 로그인 > '🔔 푸시 켜기' > 알림 허용.
   아이폰 설정 > 알림 > H군 체크리스트 > 사운드 끔.

6. GitHub Actions 탭에서 HJM iPhone Daily Push 활성화.
   매일 오전 9시(KST)에 오늘/내일 일정과 업무 마감 알림을 발송합니다.
   GitHub Actions schedule은 지연/누락될 수 있습니다.
   수동 실행은 한국시간 오전 9시가 아닐 경우 전송하지 않도록 되어 있습니다.

주의:
- 기존 Firebase 로그인 및 일정/업무/노트/운동 기록 컬렉션을 유지합니다.
- 푸시용 서비스 워커는 기존 sw.js와 같은 scope로 등록되므로 기존 오프라인 캐시 동작이 바뀔 수 있습니다.
- iOS 웹 푸시 전달과 소리/진동은 iOS 설정 및 시스템 정책의 영향을 받습니다.
- GitHub 공개 저장소에서 60일 활동이 없으면 예약 Actions가 비활성화될 수 있습니다.
- Firestore 읽기/쓰기 무료 할당량, Actions 사용량 등은 계정 및 사용량에 따라 달라질 수 있습니다.
